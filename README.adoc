== Description

Gravitee.io Inline Authentication Provider resource is used to validate user credentials against a list of users defined directly in the API configuration.

Use this resource with the **Basic Authentication** policy on the request flow.

== Compatibility with APIM

|===
| Plugin version | APIM version | Java version

| 2.x
| 4.12.x and above
| 21

| 1.x
| 4.11.x and below
| 11
|===

== Configuration

You can configure the resource with the following options :

|===
|Property |Required |Description |Type |Default

.^|users
^.^|X
|List of inline users
^.^|array
^.^|-

.^|users[].username
^.^|X
|Username
^.^|string
^.^|-

.^|users[].password
^.^|-
|Password
^.^|string
^.^|-

.^|users[].roles
^.^|-
|Roles assigned to the user
^.^|array (string)
^.^|-
|===

[source,json]
.Configuration example
----
{
    "configuration": {
        "users": [
            {
                "username": "alice",
                "password": "secret",
                "roles": ["USER"]
            },
            {
                "username": "bob",
                "password": "other-secret"
            }
        ]
    }
}
----
